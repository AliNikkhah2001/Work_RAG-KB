  • HyDE — pseudo-doc via Gemma (black-box API) feat/hyde-wiring → +10-15% recall
  • Entity-boost DSL must(original)+should(entities)
  • Query expansion (synonyms) + weighted RRF
  • Already fixed: char 3-gram MRR 0.18→0.333 (+85%)

🟡 W2: Latency 15.8s

  • Quantize reranker INT8 (optimum) 50→30 top_k

  • Target 15.8s→~6s while keeping Hit≥90%

🟢 W3: Conversational Drift

  • Multi-query beam 5 → RRF L=5 (+3-6% MRR)

  • Use detect_query_type() to trigger only conversational
