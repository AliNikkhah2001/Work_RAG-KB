How Excel tables become chunks — 5 steps

1Read sheets — openpyxl / calamine reads every sheet, first row = headers. Empty trailing columns trimmed; ~$ lock files skipped. (سطر اول = عنوان ستون‌ها)
2Normalize + detect schema — _normalize_col = re.sub(r"[\s_\-]+" ,"", lower). Then overlap ≥60% against three schemas:
reason_codes (14 cols)crm_qa (5 cols: question / answer / briefanswer / keyword / model)articles (10 cols)
3Rows → fields — for each data row, _format_cell (None→"" , float g-format, else stripped str). Empty rows dropped. Integrity check: U+FFFD / mojibake ?+Arabic warned.
Q&A also filters: row needs question AND (answer or briefanswer) else counted as skipped_incomplete; then dedup by normalized question (Arabic ي→ی, ك→ک, ZWNJ→space).
4Preprocess — clean → Persian normalise (preprocessor/pipeline.py).
5Chunk — SemanticChunker._chunk_excel_rows: one row = one chunk (never split), content formatted with Persian labels (سوال / پاسخ کامل / پاسخ کوتاه / کلیدواژه‌ها), parents per sheet.
